# 1 总则

+   文档编号：BC52-SD02
+   文档名称：知识工程 控制管理详细设计
+   目的：定义 BC-52 知识工程 SD02 控制管理子领域的详细设计方案，包括业务流程、领域模型、应用服务、接口、数据模型、前端交互、权限和测试设计，为开发团队提供可直接实现的技术蓝图
+   范围：控制点（ControlPoint）CRUD 与方法论属性配置、方案（Solution）组合与方法论属性覆盖度对比，覆盖 P1 版本完整设计
+   管理要点：二聚合模型（控制点/方案）、控制点状态机（DRAFT→PUBLISHED→RETIRED）、方法论属性结构化（时机×机制×程度）、控制点树形结构（parentId/levelPath）、5条业务规则、12个RESTful API + 1个RPC接口 + 1个出站消息
+   文档密级：【商密二级】 -- 外发必追责

## 3.6 FL-CM-06 编辑控制点

+   **功能目标**：修改控制点的名称、描述、父节点和方法论属性
+   **使用角色**：UP02 控制架构师
+   **接口对应**：P-CM-02（第6章）

+   技术实现要点：

    -   已发布控制点修改时，系统自动记录变更历史（CM-R-04），并展示影响范围提示（关联映射数和责任点数）

## 3.7 FL-CM-07 浏览与检索控制点

+   **功能目标**：按场景空间、时机、机制筛选控制点列表，支持关键字搜索和树形层级浏览
+   **使用角色**：UP02 控制架构师
+   **接口对应**：P-CM-03（第6章）

+   技术实现要点：
    -   查询路由：精确筛选（spaceType/timing/mechanism）走MySQL索引查询；关键字搜索走Elasticsearch全文检索
    -   缓存策略：列表查询不缓存（筛选条件组合多变）；详情查询走Redis缓存（30分钟TTL）
    -   分页策略：默认每页20条，最大100条；使用MySQL LIMIT+OFFSET分页
    -   树形查询：支持按parentId查询子节点列表，支持按levelPath前缀查询子树

+   异常处理如下表所示

    | 异常场景     | 处理策略                               |
    | ------------ | -------------------------------------- |
    | ES服务不可用 | 降级为MySQL LIKE查询，响应时间可能增加 |

    +   表 浏览检索异常处理

## 3.8 FL-CM-08 对比方案覆盖度

+   **功能目标**：选择两个方案，从时机和机制两个维度对比方法论属性覆盖差异
+   **使用角色**：UP02 控制架构师
+   **接口对应**：P-CM-11（第6章）

+   技术实现要点：
    -   对比逻辑：分别聚合两个方案自身的methodology属性及其所含控制点的timing和mechanism属性，生成覆盖矩阵
    -   差异计算：标注方案A独有、方案B独有、共同覆盖的时机/机制组合

## 3.9 FL-CM-09 管理控制点版本

+   **功能目标**：查看控制点版本历史列表，创建新版本，回溯到指定历史版本

## 4.5 值对象定义

### MethodologyAttribute（方法论属性）

    | 属性名        | 数据类型            | 约束                     | 业务含义                                                          |
    | ------------- | ------------------- | ------------------------ | ----------------------------------------------------------------- |
    | timings       | List<TimingEnum>    | 必填，≥1项               | 时机（多选）：T空间(PREV/DETC/RESP/RECV)；M/G空间(PREV/DETC/CORR) |
    | mechanisms    | List<MechanismEnum> | 必填，≥1项，按timing分组 | 机制（多选）：对应所选时机下的机制枚举值                          |
    | processDegree | ProcessDegree       | 可选                     | 过程类程度（值对象，含三个可选子属性）                            |
    | measureDegree | MeasureDegree       | 可选                     | 度量类程度（值对象，含四个可选子属性）                            |

    +   表 MethodologyAttribute 属性

+   processDegree 和 measureDegree 至少填写其一

### ProcessDegree（过程类程度）

+   对行为执行过程的伴随性约束，每个子属性独立开启并填写具体要求

    | 属性名  | 数据类型 | 约束 | 业务含义                                                 |
    | ------- | -------- | ---- | -------------------------------------------------------- |
    | trace   | String   | 可选 | 留痕：记录要求（如"审计日志"、"操作记录"、"变更记录"）   |
    | witness | String   | 可选 | 见证：在场要求（如"双人操作"、"四眼原则"、"监督岗"）     |
    | approve | String   | 可选 | 审批：批准要求（如"逐级审批"、"会签"、"变更委员会审议"） |

    +   表 ProcessDegree 属性

+   三个子属性均为可选，填写即表示启用该约束，值为具体要求描述

### MeasureDegree（度量类程度）

+   可量化的约束指标，每个子属性独立开启并填写具体指标值

    | 属性名    | 数据类型 | 约束 | 业务含义                                              |
    | --------- | -------- | ---- | ----------------------------------------------------- |
    | frequency | String   | 可选 | 频次：执行周期（如"每日"、"每季度"、"每年"）          |
    | duration  | String   | 可选 | 时长：保持时间（如"日志保留6个月"、"备份保留1年"）    |
    | threshold | String   | 可选 | 阈值：数值标准（如"密码≥8位"、"可用性≥99.9%"）        |
    | level     | String   | 可选 | 等级：级别标准（如"AES-256"、"TLS 1.2+"、"等保三级"） |

    +   表 MeasureDegree 属性

+   四个子属性均为可选，填写即表示启用该约束，值为具体指标描述

+   由聚合根管理，无独立业务方法
+   MethodologyAttribute（含 ProcessDegree 和 MeasureDegree）同时用于 ControlPoint 和 Solution 两个聚合，结构一致
