# 1 总则

+   文档编号：BC52-SD02
+   文档名称：知识工程 控制管理详细设计
+   目的：定义 BC-52 知识工程 SD02 控制管理子领域的详细设计方案，包括业务流程、领域模型、应用服务、接口、数据模型、前端交互、权限和测试设计，为开发团队提供可直接实现的技术蓝图
+   范围：控制点（ControlPoint）CRUD 与方法论属性配置、方案（Solution）组合与覆盖度对比、验证规则（VerificationRule）配置与关联，覆盖 P1 版本完整设计
+   管理要点：三聚合模型（控制点/方案/验证规则）、控制点状态机（DRAFT→PUBLISHED→RETIRED）、方法论属性结构化（时机×机制×程度）、7条业务规则、13个RESTful API + 2个RPC接口 + 1个出站消息
+   文档密级：【商密二级】 -- 外发必追责

## 3.8 FL-CM-07 浏览与检索控制点

+   **功能目标**：按场景空间、时机、机制筛选控制点列表，支持关键字搜索
+   **使用角色**：UP02 控制架构师
+   **接口对应**：P-CM-03（第6章）

+   技术实现要点：
    -   查询路由：精确筛选（spaceType/timing/mechanism）走MySQL索引查询；关键字搜索走Elasticsearch全文检索
    -   缓存策略：列表查询不缓存（筛选条件组合多变）；详情查询走Redis缓存（30分钟TTL）
    -   分页策略：默认每页20条，最大100条；使用MySQL LIMIT+OFFSET分页

+   异常处理如下表所示

    | 异常场景         | 处理策略                               |
    | ---------------- | -------------------------------------- |

## 3.9 FL-CM-08 对比方案覆盖度
