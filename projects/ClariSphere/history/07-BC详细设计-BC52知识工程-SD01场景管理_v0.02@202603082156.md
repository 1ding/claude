## 3.4 FL-SM-03 编辑场景点属性

+   **功能目标**：修改场景点的名称和描述
+   **使用角色**：UP02控制架构师
+   **接口对应**：P-SM-03（第6章）

+   技术实现要点：
    -   乐观锁控制：更新时携带version字段，冲突返回E-4090001
    -   名词性校验：修改名称时触发SM-R-02校验
    -   变更历史：更新操作由AOP审计切面自动记录

+   异常处理如下表所示

    | 异常场景         | 处理策略                      |
    | ---------------- | ----------------------------- |
    | 名称包含措施语义 | 阻断提交，返回校验错误        |
    | 乐观锁冲突       | 返回E-4090001，提示数据已变更 |
    | 场景点不存在     | 返回E-4040001                 |

    +   表 编辑场景点异常处理

## 3.5 FL-SM-04 浏览与检索场景树

+   **功能目标**：按T/M/G空间加载场景树，支持展开/收起和关键字搜索
+   **使用角色**：UP02控制架构师
+   **接口对应**：P-SM-01、P-SM-06（第6章）

+   技术实现要点：
    -   场景树缓存：按空间维度缓存完整场景树（Key: engineer:scenario-tree:{space}，TTL 10分钟）
    -   查询路由：优先查Redis缓存，未命中时查DB并回填
    -   关键字搜索：基于数据库LIKE查询（P1阶段场景点数据量2000+，无需引入ES）

+   异常处理如下表所示

    | 异常场景     | 处理策略             |
    | ------------ | -------------------- |
    | 缓存不可用   | 降级为直接查询数据库 |
    | 空间参数无效 | 返回E-4000007        |

    +   表 浏览与检索异常处理

```sql
-- V1.0.0__create_scenario_mgmt_tables.sql

CREATE TABLE scenario_points (
    id               BIGINT       NOT NULL COMMENT '主键',
    code             VARCHAR(64)  NOT NULL COMMENT '七层级编码',
    name             VARCHAR(100) NOT NULL COMMENT '场景点名称',
    description      VARCHAR(500) DEFAULT NULL COMMENT '场景点描述',
    space_type       VARCHAR(10)  NOT NULL COMMENT '场景空间(TECH/MGMT/GOV)',
    parent_id        BIGINT       DEFAULT NULL COMMENT '父节点ID',
    level_path       VARCHAR(500) NOT NULL COMMENT '物化路径',
    level            INT          NOT NULL DEFAULT 1 COMMENT '层级深度',
    sort_order       INT          NOT NULL DEFAULT 0 COMMENT '同级排序序号',
    business_version INT          NOT NULL DEFAULT 1 COMMENT '业务版本号',
    status           VARCHAR(20)  NOT NULL DEFAULT 'ACTIVE' COMMENT '状态',
    created_by       BIGINT       NOT NULL COMMENT '创建人ID',
    created_at       DATETIME     NOT NULL COMMENT '创建时间',
    updated_by       BIGINT       NOT NULL COMMENT '更新人ID',
    updated_at       DATETIME     NOT NULL COMMENT '更新时间',
    is_deleted       TINYINT(1)   NOT NULL DEFAULT 0 COMMENT '逻辑删除',
    version          INT          NOT NULL DEFAULT 0 COMMENT '乐观锁版本号',
    PRIMARY KEY (id),
    UNIQUE KEY uk_code (code),
    KEY idx_parent_id (parent_id),
    KEY idx_space_type (space_type),
    KEY idx_level_path (level_path),
    KEY idx_name (name)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='场景点表';

CREATE TABLE scenario_point_versions (
    id                  BIGINT       NOT NULL COMMENT '主键',
    scenario_point_id   BIGINT       NOT NULL COMMENT '场景点ID',
    business_version    INT          NOT NULL COMMENT '业务版本号',
    snapshot_name       VARCHAR(100) NOT NULL COMMENT '快照时名称',
    snapshot_space_type VARCHAR(10)  NOT NULL COMMENT '快照时空间类型',
    snapshot_parent_id  BIGINT       DEFAULT NULL COMMENT '快照时父节点ID',
    snapshot_level_path VARCHAR(500) NOT NULL COMMENT '快照时物化路径',
    created_by          BIGINT       NOT NULL COMMENT '创建人ID',
    created_at          DATETIME     NOT NULL COMMENT '创建时间',
    PRIMARY KEY (id),
    UNIQUE KEY uk_point_version (scenario_point_id, business_version),
    KEY idx_scenario_point_id (scenario_point_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='场景点版本快照表';
```
