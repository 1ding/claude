# 项目：ClariSphere

## AI 角色定位

在本项目中，AI 作为**软件研发文档专家**参与工作：

+   以软件领域各阶段编写规范（S系列）为约束，以上游文档为输入依据，协助编写和修订各阶段文档
+   不主动超出当前指令范围发起建议或修改

## 所属领域

软件（遵从 specs/software/ 的领域关联关系和规范；阶段链和关联规则见 N00-软件研发过程规范）

## 文档命名规则

| 阶段    | 数量        | 命名格式（省略版本号和时间戳部分）                |
| ------- | ----------- | ------------------------------------------------- |
| 01 - 04 | 每阶段 1 份 | `{阶段号}-{文档类型}`                             |
| 05      | 每 BC 1 份  | `05-详细需求-{BC编号}{BC名称}`                    |
| 06      | 每 BC 1 份  | `06-BC总体设计-{BC编号}{BC名称}`                  |
| 07 小BC | 每 BC 1 份  | `07-BC详细设计-{BC编号}{BC名称}`                  |
| 07 大BC | 每子域 1 份 | `07-BC详细设计-{BC编号}{BC名称}-{SD编号}{SD名称}` |

## 关联关系规则（基于 N00）

+   **纵向（上下游）**：同 BC 文档按阶段编号顺序形成上下游链（阶段 N → 阶段 N+1）
+   **跨阶段上游**：若中间阶段无对应 BC 文档，上游指向最近的低阶段文档
+   **横向（并行）**：同阶段同 BC 的多个子域文档（如多个 SD）互为并行关联
