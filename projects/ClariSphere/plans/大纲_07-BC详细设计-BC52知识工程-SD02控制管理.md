### # 4 领域模型设计

#### ## 4.1 聚合概述

+   聚合清单表：
    -   ControlPoint（控制点）：核心聚合根，含 MethodologyAttribute 值对象
    -   Solution（方案）：独立聚合根（方案与控制点是多对多，方案有独立生命周期）
    -   VerificationRule（验证规则）：独立聚合根（验证规则关联控制点但有独立CRUD）
+   聚合关系图：ASCII图（ControlPoint ←ID引用← Solution，ControlPoint ←ID引用← VerificationRule，ControlPoint ←ID引用← ScenarioPoint[SD01]）

#### ## 4.2 ControlPoint 聚合（三表模型）

+   **属性清单表**：id、code（SevenLayerCode值对象）、name、description、spaceType(T/M/G)、methodology（MethodologyAttribute值对象：timing、mechanism、degree）、requirementPointRefs[]（ID引用列表）、version、status（DRAFT/PUBLISHED/RETIRED）、createdBy、createdAt、updatedAt、versionNum（乐观锁）
+   **业务规则表**：
    -   CM-R-01 控制点编码全局唯一（BR-003）→ 创建时校验 → E-4090002
    -   CM-R-02 已发布控制点要求点引用不可为空（BR-004）→ 发布时校验 → E-4220002
    -   CM-R-03 状态流转约束（仅允许 DRAFT→PUBLISHED→RETIRED）→ 状态变更时 → E-4220001
    -   CM-R-04 已发布控制点修改须记录变更历史 → 更新时 → 无错误码（副作用）
+   **业务方法表**：
    -   create(cmd) → 创建控制点，分配编码 → CM-R-01
    -   updateAttributes(cmd) → 更新属性 → CM-R-04
    -   publish() → 发布 → CM-R-02, CM-R-03 → 产生 ControlPointPublishedEvent
    -   retire(reason) → 废止 → CM-R-03 → 产生 ControlPointRetiredEvent
    -   createVersion() → 创建新版本

#### ## 4.3 状态机定义

+   控制点状态机（引用06总体设计§6.2.1，本章细化守卫条件和副作用）
+   状态枚举表：DRAFT/PUBLISHED/RETIRED
+   状态转换规则表：
    -   DRAFT → PUBLISHED：事件=publish，守卫=requirementPointRefs非空，副作用=发布DE-04事件
    -   PUBLISHED → RETIRED：事件=retire，守卫=无，副作用=通知关联映射/责任点
+   状态机图：ASCII图

#### ## 4.4 Solution 聚合（三表模型）

+   **属性清单表**：id、name、targetDescription、controlPointIds[]（ID引用列表）、coverageSummary（值对象）、createdBy、createdAt
+   **业务规则表**：
    -   CM-R-05 方案至少包含一个控制点 → 创建时 → E-4220002
+   **业务方法表**：
    -   create(cmd) → 创建方案
    -   addControlPoint(controlPointId) → 添加控制点
    -   removeControlPoint(controlPointId) → 移除控制点
    -   calculateCoverage() → 计算时机/机制覆盖度

#### ## 4.5 VerificationRule 聚合（三表模型）

+   **属性清单表**：id、name、ruleType(AUTO/MANUAL)、frequency（FrequencyEnum值对象：REALTIME/DAILY/WEEKLY/MONTHLY/QUARTERLY）、expectedResult、controlPointIds[]（ID引用列表，≥1）、createdBy、createdAt
+   **业务规则表**：
    -   CM-R-06 验证规则必须关联≥1控制点（BR-005）→ 创建/更新时 → E-4220002
    -   CM-R-07 检查频率须为有效枚举（BR-005）→ 创建/更新时 → E-4000007
+   **业务方法表**：
    -   create(cmd) → 创建验证规则 → CM-R-06, CM-R-07
    -   update(cmd) → 更新验证规则 → CM-R-06, CM-R-07

#### ## 4.6 值对象定义

+   **MethodologyAttribute**（方法论属性）：timing（枚举）、mechanism（枚举，按timing分组）、degrees[]（枚举列表，多选）→ 简单值对象，仅属性表
+   **SevenLayerCode**（七层级编码）：L1~L7各层级值 → 简单值对象，含校验方法（全局唯一性由仓储层保证）
+   **CoverageSummary**（覆盖度概要）：timingCoverage、mechanismCoverage → 简单值对象
+   **FrequencyEnum**（检查频率枚举）：REALTIME/DAILY/WEEKLY/MONTHLY/QUARTERLY

#### ## 4.7 领域服务

+   ControlPointCodeService（控制点编码分配服务）：协调 ControlPoint 聚合和编码仓储，保证编码全局唯一
+   SolutionCoverageComparisonService（方案覆盖度对比服务）：协调两个 Solution 聚合，计算时机/机制维度差异

#### ## 4.8 领域事件清单

+   ControlPointPublishedEvent：控制点发布时触发 → 消费方：SD-06映射管理（更新映射状态）、BC-31（同步控制点数据） → 对应DE-04
+   ControlPointRetiredEvent：控制点废止时触发 → 消费方：SD-06映射管理（标记映射源废止）
