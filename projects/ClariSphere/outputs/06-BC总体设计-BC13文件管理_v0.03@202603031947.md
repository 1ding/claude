## 2.2 上下文价值定位

+   **核心价值**：为全平台提供统一、安全、可扩展的文件存储与处理服务。

+   **业务目标**：
    1.   消除各BC自行管理文件存储的重复实现，统一文件服务入口
    2.   提供标准化文件安全检测（病毒扫描+类型校验），保障平台安全
    3.   统一文件访问控制与审计，满足等保三级合规要求

+   **服务对象**：所有业务BC（通过OHS调用）。

+   **核心能力**：文件上传/下载、版本管理、在线预览、病毒扫描、临时签名URL访问控制。

## 4.2 各子领域职责说明

+   **SD01 文件生命周期（核心）**：
    +   核心职责：管理文件从上传到归档删除的完整生命周期，维护版本历史和元数据
    +   核心实体：
        +   File（File）：fileId、tenantId、originalName、storageBucket、storageKey、size、mimeType、status、uploadedBy、createdAt
        +   FileVersion（FileVersion）：versionId、fileId、versionNo、storageKey、size、createdAt
    +   核心能力：（P1）F-01单文件上传、F-02文件下载、F-03软删除、F-04版本管理、F-07签名URL、F-08元数据查询；（P2）F-09分片上传
    +   数据存储方案：MySQL（File + FileVersion 元数据记录）+ OBS（P1：客户提供的OBS，单Bucket；P2+ SaaS时切换为多Bucket隔离策略）
    +   对外接口：文件上传接口、文件下载接口、文件元数据查询接口、版本列表接口、签名URL签发接口

+   **SD02 文件处理（支撑）**：
    +   核心职责：对已存储文件执行格式转换和预览处理，生成可在线查看的预览版本并缓存
    +   核心实体：FilePreview（FilePreview）：previewId、fileId、previewType、previewKey、generatedAt
    +   核心能力：（P2+）F-06文件在线预览（PDF/图片/Office）；（P2+）F-10文件标签管理
    +   数据存储方案：MinIO（预览文件缓存，独立Bucket）+ Redis（预览URL缓存，TTL=1h）
    +   对外接口：预览URL获取接口（GET /v1/files/{id}/preview）

+   **SD03 文件安全（横切）**：
    +   核心职责：横切支撑各子领域，在文件上传和访问链路中提供安全检测和访问控制；横切范围：P1阶段为SD01，P2+扩展至SD02
    +   核心实体：ScanRecord（ScanRecord）：scanId、fileId、scanEngine、result、threat、scannedAt
    +   核心能力：P1为SD01提供病毒扫描（通过VirusScanPort，方案A/B可插拔）和文件类型白名单校验（MIME+Magic Number双检）能力；P2+扩展支撑SD02
    +   数据存储方案：MySQL（扫描结果记录）
    +   对外接口：被动型（接收SD01上传完成领域事件触发扫描）；主动型（提供扫描状态查询接口）

+   BC-13 协作设计决策如下表所示

## 5.5 上下游依赖治理规则

+   查询类依赖（元数据查询、预览URL）：允许同步，走Redis缓存，超时3s，熔断阈值50%
+   命令类依赖（上传/删除）：同步确认OBS写入成功后返回；扫描异步化，不阻塞上传响应
+   跨BC一致性：文件元数据与OBS对象一致性通过补偿任务定期核对
+   上游模型变更（IAM）：本BC IamAcl 隔离，禁止直接依赖IAM领域模型
+   双向依赖：无双向依赖

## 8.1 认证方案

## 8.5 数据权限通用策略

+   租户级：P1无需（私有化单租户）；P2+ SaaS时启用OBS路径前缀+MySQL tenant_id过滤
+   个人级：uploadedBy 过滤（普通用户仅访问本人上传或显式共享的文件）

## 8.6 前端权限控制策略

+   按钮级：上传/删除/预览按钮基于权限码决定是否展示
+   文件列表：仅展示当前用户有权访问的文件（服务端过滤）

## 8.7 敏感数据与审计

+   敏感数据：OBS Bucket 服务端加密（具体算法以客户OBS配置为准，建议AES-256）；元数据表不存储文件内容
+   传输安全：HTTPS；文件访问通过临时签名URL（PreSignedURL），有效期受限
+   审计日志：记录上传/下载/删除/病毒拦截/权限拒绝事件；保留策略：6个月
+   输入校验：文件类型白名单（MIME类型+Magic Number双检）；单文件大小限制（P1：≤500MB）；路径规范化防路径遍历攻击

    | OBS分片上传（P2）   | 大文件（>100MB）             | 提升大文件上传吞吐，支持断点续传 | 分片合并逻辑复杂，需清理未完成的分片               |
    | 异步病毒扫描        | 所有上传                     | 上传响应时间不受扫描影响         | 文件上传后短暂处于SCANNING状态，业务BC需处理此状态 |

    +   表 BC-13 性能优化手段
