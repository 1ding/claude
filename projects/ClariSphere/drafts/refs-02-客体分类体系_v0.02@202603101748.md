# 1 概述

+   文档编号：GUIDE-REG-002
+   文档名称：监管条文拆解客体分类体系
+   文档密级：内部资料

## 1.1 目的

+   本文档定义监管条文结构化拆解中"客体"字段的完整分类体系，供拆解指南（GUIDE-REG-001）引用。
+   分类体系采用 T/M/G 三类框架，覆盖监管条文中出现的全部客体类型。

## 1.2 T/M/G 框架定义

+   T/M/G 是对监管义务作用对象的语义分类，三类定义如下：

| 类别 | 全称         | 含义                               | 典型表现                         |
| ---- | ------------ | ---------------------------------- | -------------------------------- |
| T    | 技术/设施/资源 | 被保护或被处理的技术性对象         | 数据、系统、网络、设备           |
| M    | 管理/活动    | 被规范或被约束的活动或过程         | 开发、运维、风险评估、应急响应   |
| G    | 治理/架构    | 被要求建立或维护的制度与组织结构   | 管理制度、组织机构、评估机制     |

+   填写格式：`{代码} {名称}`，如 `T1.3 个人信息`、`M3.1 变更管理`、`G2.2 安全组织架构`。
+   多客体用分号分隔。

## 1.3 参考来源

+   T 类：数据安全法、网络安全法等数据/系统分类体系。
+   M 类：参考 DSEF 第 3 部分（管理控制实施指南）控制域结构。
+   G 类：参考 DSEF 第 2 部分（治理控制实施指南）控制域结构。

# 2 T 类：技术/设施/资源

## 2.1 分类总览

```graph
T 技术/设施/资源
├── T1 数据资产
├── T2 系统与平台
├── T3 网络与通信
└── T4 终端与设备
```

## 2.2 T1 数据资产

+   定义：以数字形式存在、具有独立保护价值的数据集合。

| 代码 | 名称         | 说明                                             |
| ---- | ------------ | ------------------------------------------------ |
| T1.1 | 重要数据     | 法规定义的重要数据目录中列明的数据               |
| T1.2 | 国家核心数据 | 关系国家安全、国民经济命脉、重要民生的数据       |
| T1.3 | 个人信息     | 与可识别自然人相关的各类信息，含敏感个人信息     |
| T1.4 | 政务数据     | 国家机关在履行法定职责中收集和产生的数据         |
| T1.5 | 商业数据     | 企业经营活动中产生的商业秘密及一般业务数据       |
| T1.6 | 一般数据     | 不属于以上分类的其他数据                         |

## 2.3 T2 系统与平台

+   定义：承载数据处理或业务运行的软硬件平台。

| 代码 | 名称           | 说明                                             |
| ---- | -------------- | ------------------------------------------------ |
| T2.1 | 业务应用系统   | 直接支撑业务运营的应用软件系统                   |
| T2.2 | 基础设施平台   | 云平台、操作系统、虚拟化平台等基础运行环境       |
| T2.3 | 数据库         | 结构化或非结构化数据的存储管理系统               |
| T2.4 | 中间件与接口   | 系统间通信与集成的中间层组件及 API               |
| T2.5 | 关键信息基础设施 | 依法认定的关键信息基础设施                      |

## 2.4 T3 网络与通信

+   定义：承载数据传输的网络基础设施。

| 代码 | 名称       | 说明                                     |
| ---- | ---------- | ---------------------------------------- |
| T3.1 | 内部网络   | 组织内部局域网及专网                     |
| T3.2 | 互联网接入 | 对外互联网出口及相关边界设施             |
| T3.3 | 通信链路   | 广域网、专线、VPN 等跨地点通信链路       |
| T3.4 | 无线网络   | Wi-Fi、4G/5G 等无线接入网络              |

## 2.5 T4 终端与设备

+   定义：参与数据处理的物理端侧设备。

| 代码 | 名称     | 说明                                     |
| ---- | -------- | ---------------------------------------- |
| T4.1 | 服务器   | 数据中心及机房内的物理或虚拟服务器       |
| T4.2 | 用户终端 | PC、工作站等办公终端                     |
| T4.3 | 移动设备 | 手机、平板等移动办公设备                 |
| T4.4 | IoT 设备 | 工控、传感、摄像头等物联网设备           |

# 3 M 类：管理/活动

## 3.1 分类总览

```graph
M 管理/活动
├── M1 数据生命周期
├── M2 项目与开发
├── M3 运维安全（DSEF: OPSS）
├── M4 安全运营（DSEF: SECO + EMRG）
├── M5 风险与合规（DSEF: RISK + CPLI + CERT）
├── M6 人员与协作（DSEF: PERN + SUPP + OUTS）
└── M7 业务交互
```

## 3.2 M1 数据生命周期

+   定义：数据从产生到销毁全过程中的各类处理活动。

| 代码 | 名称     | 说明                               |
| ---- | -------- | ---------------------------------- |
| M1.1 | 数据采集 | 通过各类方式获取和录入数据         |
| M1.2 | 数据存储 | 数据的持久化保存和管理             |
| M1.3 | 数据处理 | 对数据进行加工、分析、使用         |
| M1.4 | 数据传输 | 在系统间或组织间传送数据           |
| M1.5 | 数据共享 | 向其他主体开放或提供数据           |
| M1.6 | 数据出境 | 将数据传输至境外或提供境外主体使用 |
| M1.7 | 数据脱敏 | 对数据进行匿名化或去标识化处理     |
| M1.8 | 数据销毁 | 对数据进行不可恢复的删除或销毁     |

## 3.3 M2 项目与开发

+   定义：信息系统从立项到上线的全生命周期工程活动（对应 DSEF: PRJM 项目管理、DEVS 开发安全）。

| 代码 | 名称         | 说明                                     |
| ---- | ------------ | ---------------------------------------- |
| M2.1 | 项目安全管理 | 在项目立项和执行过程中的安全管理活动     |
| M2.2 | 需求分析     | 系统需求的识别、定义和安全需求分析       |
| M2.3 | 系统设计     | 系统架构设计及安全架构设计               |
| M2.4 | 安全开发     | 遵循安全开发规范的编码活动（SDL）        |
| M2.5 | 安全测试     | 渗透测试、代码审查、安全扫描等测试活动   |
| M2.6 | 上线发布     | 系统投产上线及发布管理                   |
| M2.7 | 版本管理     | 软件版本控制与配置基线管理               |

## 3.4 M3 运维安全

+   定义：系统上线后日常运行维护中的安全管理活动（对应 DSEF: OPSS 运维安全）。

| 代码 | 名称     | 说明                                     |
| ---- | -------- | ---------------------------------------- |
| M3.1 | 变更管理 | 对系统配置、功能或环境的变更控制         |
| M3.2 | 配置管理 | 系统配置基线的建立、维护与核查           |
| M3.3 | 补丁管理 | 安全补丁的识别、测试、分发与部署         |
| M3.4 | 账号管理 | 账号的创建、授权、变更和注销生命周期管理 |
| M3.5 | 访问控制 | 对系统资源的访问权限管控                 |
| M3.6 | 备份恢复 | 数据和系统的备份、验证与恢复             |
| M3.7 | 监控运营 | 对系统运行状态的持续监测与告警           |
| M3.8 | 日志审计 | 日志的采集、存储、分析与审计             |
| M3.9 | 资产管理 | 信息资产的识别、登记与生命周期管理       |

## 3.5 M4 安全运营

+   定义：以保持安全态势为目的的专项安全活动（对应 DSEF: SECO 安全运营、EMRG 应急管理）。

| 代码 | 名称         | 说明                                         |
| ---- | ------------ | -------------------------------------------- |
| M4.1 | 威胁情报     | 安全威胁信息的获取、分析与共享               |
| M4.2 | 漏洞管理     | 漏洞的识别、评估、修复与跟踪                 |
| M4.3 | 渗透测试     | 模拟攻击以评估系统安全性的主动测试活动       |
| M4.4 | 安全监测     | 对网络和系统的持续安全态势感知               |
| M4.5 | 事件响应     | 安全事件的检测、处置、溯源与恢复             |
| M4.6 | 应急演练     | 安全事件应急处置流程的模拟演练               |
| M4.7 | 安全意识培训 | 面向全员的安全知识和技能培训                 |

## 3.6 M5 风险与合规

+   定义：以识别和管控风险、满足合规要求为目的的管理活动（对应 DSEF: RISK 风险管理、CPLI 合规管理、CERT 认证管理）。

| 代码 | 名称     | 说明                                         |
| ---- | -------- | -------------------------------------------- |
| M5.1 | 风险评估 | 对信息资产安全风险的识别、分析与评价         |
| M5.2 | 风险处置 | 对已识别风险的应对措施规划与执行             |
| M5.3 | 合规检查 | 对法规、标准合规状态的核查与评估             |
| M5.4 | 安全审计 | 对安全措施有效性和合规性的独立审查           |
| M5.5 | 认证管理 | 安全资质认证的申请、维护与年检管理           |

## 3.7 M6 人员与协作

+   定义：人员安全管理及与外部主体协作的相关活动（对应 DSEF: PERN 人员管理、SUPP 供方管理、OUTS 外包管理、EXTN 外部协作）。

| 代码 | 名称     | 说明                                         |
| ---- | -------- | -------------------------------------------- |
| M6.1 | 人员背景审查 | 入职前及在职期间的人员背景核查           |
| M6.2 | 人员授权管理 | 人员角色权限的分配与定期审查             |
| M6.3 | 供方管理 | 硬件、软件及服务供应商的安全管理         |
| M6.4 | 外包管理 | 外包服务的安全要求设定与履约监督         |
| M6.5 | 外部协作 | 与合作机构的数据共享与安全协同           |
| M6.6 | 文档管理 | 安全文档的制定、版本控制与归档（DSEF: DOCS）|
| M6.7 | 记录管理 | 安全活动记录的留存与销毁（DSEF: RECD）  |

## 3.8 M7 业务交互

+   定义：与外部主体发生数据或服务交互的业务活动。

| 代码 | 名称     | 说明                                     |
| ---- | -------- | ---------------------------------------- |
| M7.1 | 数据交易 | 数据产品或数据服务的买卖与交换           |
| M7.2 | 数据调取 | 依法定程序向主体调取数据                 |
| M7.3 | 接口管理 | 对外开放接口的注册、认证与访问控制管理   |

# 4 G 类：治理/架构

## 4.1 分类总览

```graph
G 治理/架构
├── G1 价值与方向（DSEF: GOV.VALU + GOV.DRCT）
├── G2 组织架构（DSEF: GOV.ORGN）
├── G3 制度体系（DSEF: GOV.MECH + POLC）
└── G4 评估与监督（DSEF: GOV.ASSR + GOV.EVAL + SUPV + PERF）
```

## 4.2 G1 价值与方向

+   定义：组织安全治理的战略导向与价值主张（对应 DSEF: GOV.VALU 安全价值集、GOV.DRCT 安全方向集）。

| 代码 | 名称         | 说明                                         |
| ---- | ------------ | -------------------------------------------- |
| G1.1 | 安全使命与愿景 | 组织安全管理的根本目的和长期期望状态       |
| G1.2 | 安全战略     | 安全目标的中长期规划与资源配置策略           |
| G1.3 | 安全方针     | 组织安全行为的总体原则和管理承诺             |
| G1.4 | 安全目标体系 | 可量化、可跟踪的分层安全目标设定             |
| G1.5 | 安全文化     | 组织内安全意识、行为规范与价值观建设         |

## 4.3 G2 组织架构

+   定义：安全职责的载体——机构、角色与责任体系（对应 DSEF: GOV.ORGN 安全组织集）。

| 代码 | 名称           | 说明                                                     |
| ---- | -------------- | -------------------------------------------------------- |
| G2.1 | 治理模式       | 安全治理的决策模式与委员会架构（如 CISO 设置、三道防线）|
| G2.2 | 安全组织架构   | 安全职能部门的设置、层级与汇报关系                       |
| G2.3 | 权责划分       | 基于 RACI 的安全职责边界定义与分工设计                   |
| G2.4 | 安全职能岗位   | 具体安全岗位的设置，如数据安全负责人、DPO               |
| G2.5 | 监管协调机制   | 跨部门、跨机构的安全协调与信息共享机制                   |

## 4.4 G3 制度体系

+   定义：约束安全活动的规则、标准与规范性文件体系（对应 DSEF: GOV.MECH 安全机制集、POLC 制度管理）。

| 代码 | 名称           | 说明                                                 |
| ---- | -------------- | ---------------------------------------------------- |
| G3.1 | 制度架构体系   | 安全管理制度的分层设计，如政策—标准—规程三级体系     |
| G3.2 | 安全管理制度   | 覆盖各管理域的具体安全管理规定                       |
| G3.3 | 数据分类分级制度 | 数据分类、分级标准及保护要求的制度设计             |
| G3.4 | 专项安全制度   | 针对特定领域的专项安全制度，如密码管理、人员管理规定 |
| G3.5 | 合规框架       | 将法规要求转化为内部控制规范的体系设计               |
| G3.6 | 应急预案       | 安全事件应急处置流程与响应规程的文件体系             |
| G3.7 | 技术框架与标准 | 技术实施规范、安全基线与架构标准（DSEF: GOV.MECH.FRMW）|

## 4.5 G4 评估与监督

+   定义：对安全体系运行状况进行持续监督和评价的机制（对应 DSEF: GOV.ASSR 安全监督集、GOV.EVAL 安全评价集、SUPV 监督检查、PERF 绩效测量）。

| 代码 | 名称         | 说明                                             |
| ---- | ------------ | ------------------------------------------------ |
| G4.1 | 安全审计机制 | 独立的安全审计制度安排与审计权限设计             |
| G4.2 | 监督检查机制 | 对安全措施落实情况的日常检查与专项督查机制       |
| G4.3 | 安全评估体系 | 系统性安全评估的流程、方法与标准体系             |
| G4.4 | 合规认证机制 | 安全资质认证与第三方合规评估的制度安排           |
| G4.5 | 绩效评价与问责 | 安全绩效指标体系、评价方式与问责激励机制       |
