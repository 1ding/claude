## 2.6 并发与幂等策略

+   **乐观锁方案**：TenantAsset、AssetImportTask 均含整型 `version` 字段。更新时使用 `WHERE id=? AND version=?` 检测并发冲突；冲突时抛出 OptimisticLockException，返回 E-4093503（CONCURRENT_CONFLICT）。

+   下表说明各写接口的幂等保证策略。

    | 接口类型      | 幂等键生成规则                                   | 存储方式            | 有效期 | 重复请求处理       |
    | ------------- | ------------------------------------------------ | ------------------- | ------ | ------------------ |
    | 创建导入任务  | `tenant_id + file_id`（BC-13 返回的唯一文件 ID） | 数据库唯一索引      | 持久   | 返回已存在任务 ID  |
    | 确认导入      | `task_id`（一个任务只能确认一次，状态机约束）    | 数据库业务约束      | 持久   | 返回 E-4093502     |
    | 取消导入任务  | `task_id`（已取消任务再次取消，幂等返回成功）    | 数据库状态字段      | 持久   | 幂等返回成功       |
    | 手工创建资产  | `tenant_id + asset_code`（资产编号在租户内唯一） | 数据库唯一索引      | 持久   | 返回 E-4093501     |
    | 编辑/停用资产 | 客户端传入 `version` 字段，乐观锁保证            | 数据库 version 字段 | 持久   | 冲突返回 E-4093503 |

    +   表 幂等性保证策略

+   **长流程防重入**：导入任务进入 PARSING 状态后申请 Redis 分布式锁（Key 为 `asset_import_lock:{taskId}`），防止同一任务重复触发解析 Worker。锁随解析完成（PARSED 或 FAILED）自动释放；超时时间 70 秒（解析超时 60 秒 + 10 秒余量）。

    | 关联错误码 | E-4043501、E-4043502、E-4093503（并发冲突）、E-4223502（编号不可改） |

    +   表 API-AM-08 契约概述

+   请求契约：Path 参数 assetId（UUID）；Body 字段：assetName（可选）、assetType（可选）、categoryId（可选）、description（可选）、version（必填，乐观锁）。

+   Mock：version 不匹配时返回 `{ "code": "E-4093503", "message": "数据已被修改，请刷新后重试" }`（HTTP 409）。

### 6.4.9 API-AM-09 停用资产 / API-AM-10 启用资产

    -   API-AM-10：POST /api/v1/tenant-deployment/assets/{assetId}/activate，权限 PERM-AM-05，响应返回 `{ status: "ACTIVE", version: 3 }`

# 附录 A：专属错误码定义

+   本附录汇总 SD-01 新增的专属错误码，按错误类型分类。错误码格式遵循《P02-软件开发错误代码规范》，BC-35 的 BB 编码为 35，SD-01 预留 SS 序号 01-20。

+   冲突类错误码（HTTP 409）：

    | 错误码    | enum 常量                     | 说明                             |
    | --------- | ----------------------------- | -------------------------------- |
    | E-4093501 | ASSET_CODE_DUPLICATE          | 资产编号在本租户内已存在         |
    | E-4093502 | IMPORT_TASK_ALREADY_CONFIRMED | 导入任务已确认，不可重复确认     |
    | E-4093503 | CONCURRENT_CONFLICT           | 乐观锁冲突，数据已被其他操作修改 |
    | E-4093504 | IMPORT_ROW_ALL_INVALID        | 全部行校验失败，无有效行可导入   |

+   资源不存在错误码（HTTP 404）：

    | 错误码    | enum 常量                | 说明                 |
    | --------- | ------------------------ | -------------------- |
    | E-4043501 | ASSET_CATEGORY_NOT_FOUND | 指定的资产分类不存在 |
    | E-4043502 | ASSET_NOT_FOUND          | 资产不存在           |
    | E-4043503 | IMPORT_TASK_NOT_FOUND    | 导入任务不存在       |

+   业务逻辑错误码（HTTP 422）：

    | 错误码    | enum 常量                  | 说明                                        |
    | --------- | -------------------------- | ------------------------------------------- |
    | E-4223501 | IMPORT_TASK_STATUS_INVALID | 当前任务状态不允许此操作（状态机约束）      |
    | E-4223502 | ASSET_CODE_IMMUTABLE       | 资产编号一经创建不可修改                    |
    | E-4223503 | CATEGORY_HAS_CHILDREN      | 分类下存在子分类，不可删除（P2 分类管理用） |
