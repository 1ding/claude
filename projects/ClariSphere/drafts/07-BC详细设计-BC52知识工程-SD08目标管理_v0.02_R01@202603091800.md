# 1 总则

+   文档编号：BC52-SD08
+   文档名称：知识工程 目标管理详细设计
+   目的：定义 BC-52 SD08 目标管理子领域的详细设计方案，建立基础目标受控词表与具体目标全生命周期管理机制，为 SD04 要求管理、SD02 控制管理、SD06 映射管理提供标准化目标分类基础
+   范围：BasicObjective（基础目标）聚合、ContextualObjective（具体目标）聚合、ObjectiveGap（目标缺口申请）聚合的完整设计，含目标缺口发现与闭环处理流程
+   管理要点：双层目标模型（抽象基础目标+场景化具体目标）、目标缺口闭环机制、方案B松耦合（resourceType自维护枚举）、三向服务接口（SD04/SD02/SD06）、DRAFT→PUBLISHED发布管控
+   文档密级：【商密二级】 -- 外发必追责

+   流程图如下所示

         │
         ▼

         │
         ▼
    [系统] 校验三维组合唯一性 ──冲突──▶ 返回 E-4095232
