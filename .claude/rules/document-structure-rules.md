# 文档通用结构规范（摘自 C11）

本规则常驻加载，适用于所有文档输出。完整规范见 `specs/common/outputs/C11-文档通用结构规范_v0.02@202603041601.md`。

## 文档分类

-   **规范类**（编写规范、通用规范、过程规范、术语规范）：完整结构（五分区）。
-   **交付类**（需求文档、设计文档、战略规划、测试报告）：完整结构（五分区）。
-   **辅助类**（清单、记录、索引、模板）：简化结构（标题+内容）。

## 完整结构文档的五分区（固定顺序）

1.  **总则**（必须，首位）：标题不强制使用"总则"，可根据内容命名。必含要素：文档编号、文档名称、文档密级。
2.  **正文**（必须，从 `# 2` 开始）：单章 ≤ 1 万汉字。
3.  **规范性附录**（可选）：执行配套——模板、文档骨架。
4.  **资料性附录**（可选）：理解辅助——术语、方法论、教学、检查清单。
5.  **修订记录**（必须，末位）：标题 `# 修订记录`。

## 简化结构文档

+   必含：标题、内容。可选：修订记录。
+   清单类用表格形式；记录类用时间序列条目；索引类用固定格式；模板类用可填充结构。

## 附录编号与排序

+   编号格式：`附录A`、`附录B`……按字母递增。
+   排序：规范性附录排在资料性附录之前。
+   标题格式：

-   规范性：`# 附录{letter}（规范性）{标题}`
-   资料性：`# 附录{letter}（资料性）{标题}`

## 附录分类

+   索引类（资料性）：术语表（三层术语体系）、缩略语表、参考文献。
+   配套类（规范性）：裁剪规则、文档骨架、模板集合。检查清单为资料性。
+   辅助类（资料性）：文档说明、内容释义、补充示例、应用指南。

## 术语表附录

+   资料性附录，三层结构：

-   业界通用术语：仅列名称。
-   天帷通用术语：列名称 + 引用 C99。
-   文档专有术语：完整定义。

## 密级

+   三级：商密一级（仅限指定人员）、商密二级（外发必追责）、内部资料（不主动对外公开）。
+   默认：内部资料。

## 修订记录

+   格式：表格（版本号 | 日期 | 修订内容 | 修订人）。
+   行宽上限：180（中文=2，英文/数字/符号=1）。
+   AI 修订编号：R.01, R.02... 顺序递增，用户指示时归并为正式版本号。
+   排列顺序：按时间正序（最早在上，最新在下）。
