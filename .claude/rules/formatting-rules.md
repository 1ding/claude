# Markdown 排版格式规范（摘自 C02）

本规则常驻加载，适用于所有文档输出。完整规范见 `specs/common/outputs/C02-排版格式规范_v0.02@202603041608.md`。

## 符号使用

| 符号        | 用途                                               |
| ----------- | -------------------------------------------------- |
| `+`         | 通用内容行标记（段落、说明、描述等所有非列表内容） |
| `-`         | 列表项标记（仅用于真正的枚举/并列项）              |
| `#`         | 标题标记                                           |
| ` ``` `     | 代码块/图块起止标记                                |

+   缩进单位：**4 空格/层**。
+   除标题（`#`）、列表项（`-`）、代码块（` ``` `）三类行外，所有内容行应以 `+` 开头。
+   不应使用空段落；内容行不得缺少 `+` 前缀而留空。

## 禁用语法

+   以下 Markdown 语法不应使用：

-   `>` 引用块
-   `[^]` 脚注
-   `- [ ]` 任务列表
-   `---` 或 `***` 分隔线（表格分隔行除外）
-   `*` 作为列表符号

## 标题层级

+   最多使用 6 级，格式：`# 1 一级` → `## 1.1 二级` → `### 1.1.1 三级` → `#### 四级` → `##### 五级` → `###### 六级`。
+   正文从 `#`（一级标题）开始；不应在一级标题上方设置文档名称标题。
+   层级按顺序递进，不应跳级（如从一级直接跳到三级）。

## 缩进规则

-   **标题下直接跟随的 `+`**：不缩进，紧贴左边界。
-   **嵌套内容**：每深一层缩进 4 空格。
-   **列表项 `-`**：与同级 `+` 保持相同缩进深度。
-   **`-` 下的子级**：子 `-` 或子 `+` 在父 `-` 基础上再缩进 4 空格。
-   **嵌套自由度**：`+` 下可嵌套 `-`，`-` 下可嵌套 `+`，自由组合。

## 表格

-   使用标准 Markdown 表格语法（`|` 分隔列，`---` 定义表头分隔行）。
-   表头必填，不得留空。
-   每行显示宽度不超过 **360**（中文字符及中文符号各计 2，英文字符、数字及英文符号各计 1）。
-   禁止使用 `<br>` 换行；需换行时拆分为多行（每行对应独立内容）。
-   填充空格以确保等宽字体下各列视觉对齐。

## 图

-   仅允许使用 **ASCII 文本图**；不应嵌入图片文件或使用非文本图形。
-   图块代码围栏语言标识：` ```graph `（`graph` 为本规范定义的自定义标识符）。
-   每行显示宽度不超过 **360**（计算规则同表格）。
-   推荐字符：`─ │ ┌ ┐ └ ┘ ├ ┤ ┬ ┴ ┼ ▶ ▼ ◆ ●`
-   禁用字符（不应作为图形元素）：`+`、`-`、`|`、`*`。
-   同级元素须水平或垂直对齐；同类元素须保持相同大小。

## 图表标题与说明

-   **说明文字**：置于图/表**上方**，完整陈述句，不以冒号结尾；使用 `+` 行标记，不缩进。
-   **标题**：置于图/表**下方**，简洁名词短语。
-   图、表、代码块相对其上方的说明文字**缩进 4 空格**（体现从属关系）。
-   图/表**不编号**；引用使用位置性语言（"上图"/"下表"/"以下代码"）或直接引用标题文字。

## 代码块

-   代码块必须注明语言标签，不应省略。
-   常用标签：`json`、`yaml`、`toml`、`python`、`java`、`typescript`、`go`、`sql`、`bash`、`text`。
-   嵌套场景：外层使用 4 空格缩进处理，不应使用反引号嵌套。

## 公式

-   行内公式：`$...$`
-   块级公式：`$$...$$`

## 允许的 HTML 标签

+   正文中仅允许使用以下 4 种 HTML 标签，不应使用其他 HTML 标签：`<sup>`（上标）、`<sub>`（下标）、`<mark>`（高亮）、`<u>`（下划线）。
