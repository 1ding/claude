# 跨文档一致性对齐

对目标文档与已加载的关联文档进行系统性一致性比对，输出差异报告，可选自动修正。

## 适用场景

-   编写或修订了上游文档后，检查下游文档是否仍一致
-   并行文档之间的术语、接口、协议对齐
-   总体设计修改后，检查各子系统设计是否同步

## 不适用场景（请改用对应 skill）

-   只修改文档内部内容，不涉及跨文档 → `/doc-fix` 或 `/doc-revise`
-   系统性修订（多种驱动类型混合） → `/doc-revise`
-   只检查格式问题 → `/doc-fmt`

## 输入

$ARGUMENTS

用户可指定：
-   **关联类型**（可选）：上下游 / 总分 / 并行
-   **比对范围**（可选）：全文 / 指定章节

## 先决条件检查与模式判断

**在执行任何步骤前，先完成以下检查：**

**参数解析（目标文档）**

若 $ARGUMENTS 首个词为文件路径（含 `/` 或以 `.md` 结尾）：
1.  提取文件路径和可选章节参数（格式 `N` 或 `N-M`，置于路径之后）
2.  读取目标文件（有章节参数时按 `# ` 一级标题切分，只加载指定章节）
3.  输出 `[LOADED target] {文件路径} | ~{tokens} tokens`
4.  将路径及章节参数之后的剩余内容视为本命令的关联类型/比对范围输入

**判断运行模式**

扫描当前会话历史中的 `[LOADED *]` 记录（含步骤1自动加载的结果）：

| 条件 | 模式 |
| ---- | ---- |
| 有 `[LOADED target]` + 至少一条关联文档 | **标准模式**（有主次） |
| 无 `[LOADED target]` + 至少两条 `[LOADED parallel]` | **对等模式**（无主次） |
| 其他 | 中止并提示 |

如不满足任一模式，输出以下提示并**立即中止**：

> ⚠️ 缺少必要的加载，请选择以下方式之一：
> -   **标准模式**（路径直接传入）：
>     ```
>     /doc-align /path/to/目标文档
>     /doc-align /path/to/目标文档 3       # 只加载第3章
>     /doc-align /path/to/目标文档 1-2     # 只加载第1、2章
>     ```
>     然后执行 `/load-upstream` `/load-downstream` `/load-parallel` 中至少一项
> -   **标准模式**（先加载）：`/load-target` 指定目标文档 + `/load-upstream` `/load-downstream` `/load-parallel` 中至少一项
> -   **对等模式**（并行文档互查，无主次）：`/load-parallel` 加载至少两个文档，不执行 `/load-target`

## 执行步骤

**容量评估**（执行比对前）：扫描会话历史中所有 `[LOADED *]` 记录，估算合计 tokens（字节数 ÷ 3.5）：
-   ≤ 120K → 继续执行
-   120K–160K → ⚠️ 容量偏紧：一致性对齐须同时读取全部关联文档，分批会明显影响比对质量，建议切换模型（`/model sonnet-1m`）
-   > 160K → 🔴 容量紧张：强烈建议切换模型（`/model sonnet-1m`）；如不切换，只能缩减比对范围

### 分支 A：标准模式（有 target）

#### A1. 确认文档与关联类型

-   从会话历史获取目标文档（最近一条 `[LOADED target]`）
-   从会话历史获取全部关联文档（`[LOADED upstream]`、`[LOADED downstream]`、`[LOADED parallel]`）
-   确认关联类型（用户指定 > 会话中加载的角色标记 > 询问用户）

#### A2. 确定比对维度

根据关联类型确定比对重点（维度定义详见 `.claude/rules-ext/association-rules.md`）：

| 比对维度 | 上下游 | 总分 | 并行 |
| --- | --- | --- | --- |
| 流程/状态转换 | ★重点（传递完整性） | ○一般 | ○一般 |
| 范围覆盖 | ○一般 | ★重点（是否遗漏） | ○一般 |
| 职责/模块划分 | ○一般 | ★重点（分解一致性） | ★重点（边界清晰性） |
| 共享协议/公共接口 | ○一般 | ○一般 | ★重点（契约一致性） |
| 约束/指标继承 | ★重点（向下传递） | ★重点（逐级分解） | ○一般 |
| 术语一致性 | ★重点 | ★重点 | ★重点 |

#### A3. 执行比对

-   通读目标文档和关联文档（均已在会话上下文中）
-   按比对维度逐项检查
-   区分实质差异和层级适配差异（不同层级文档的详略程度天然不同，不视为不一致）

#### A4. 输出差异报告

```
---一致性比对报告（标准模式）---

目标文档：{文档名}
关联文档：{文档名}（{关联类型}）
比对范围：{全文 / 指定章节}

差异汇总：
| 序号 | 比对维度 | 目标文档位置 | 关联文档位置 | 差异描述 | 差异程度 | 修订方向 |
| ---- | -------- | ------------ | ------------ | -------- | -------- | -------- |
| 1    | 术语     | 3.2          | 2.1          | ...      | 中等     | 以关联文档为准 |

总计：严重 X 项，中等 X 项，轻微 X 项
```

#### A5. 可选修正

```
是否需要自动修正？
- 回复"修正" → 按修订方向自动修正目标文档，创建新版本
- 回复"修正 + 序号" → 只修正指定的差异项
- 回复"不修正" → 仅保留报告
```

### 分支 B：对等模式（无 target，并行文档互查）

适用于地位平等的兄弟文档，无主次之分，比对结果不预设修订方向。

#### B1. 确认文档列表

-   从会话历史收集全部 `[LOADED parallel]` 记录，按加载顺序编号（文档1、文档2……）
-   列出文档清单，确认比对范围（全文 / 用户指定章节）

#### B2. 确定比对维度

并行文档互查固定使用并行关联的比对重点：

| 比对维度 | 重要性 |
| -------- | ------ |
| 术语一致性 | ★重点 |
| 职责/模块划分（边界清晰性） | ★重点 |
| 共享协议/公共接口（契约一致性） | ★重点 |
| 流程/状态转换 | ○一般 |
| 范围覆盖 | ○一般 |
| 约束/指标 | ○一般 |

#### B3. 执行比对

-   对所有文档两两比对（N 个文档共 N×(N-1)/2 对）
-   每对比对按维度逐项检查
-   不预设哪个文档"正确"，只记录差异事实

#### B4. 输出差异报告

```
---一致性比对报告（对等模式）---

参与文档：
  [1] {文档名}
  [2] {文档名}
  [3] {文档名}（如有）
比对范围：{全文 / 指定章节}

差异汇总：
| 序号 | 比对维度 | 文档[X]位置 | 文档[Y]位置 | 差异描述 | 差异程度 |
| ---- | -------- | ----------- | ----------- | -------- | -------- |
| 1    | 术语     | [1] 3.2     | [2] 2.1     | ...      | 中等     |

总计：严重 X 项，中等 X 项，轻微 X 项
```

#### B5. 可选修正

由于无主次之分，修正前需用户决策：

```
发现 X 处差异，如需修正请指定：
- "修正 [文档编号] 第N项" → 修正指定文档的指定差异项，创建新版本
- "修正 [文档编号] 全部" → 修正指定文档的所有差异项
- "不修正" → 仅保留报告
```

修正后在对应文档的 drafts/ 中创建新版本（按版本管理规范递增修订号）。

## 不执行

-   **不加载**规范文档（使用会话中已加载的规范）
-   **不执行**全面质量检查
