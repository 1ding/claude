# 从交接计划恢复会话

读取指定交接计划文件，恢复上一会话的工作上下文，从断点继续执行。

## 用法

```
/session-resume <交接文件路径>
```

示例：

```
/session-resume projects/ClariSphere/plans/交接_监管条文拆解指南_202603141200.md
```

## 执行步骤

### 第一步：加载交接文件

读取指定路径的交接计划文件，提取以下信息：

- 任务类型与项目名称
- 已完成内容列表
- 中断点（具体到哪一节、哪一步）
- 下次会话所需加载文档列表
- 开放问题与生效假设

### 第二步：加载所需文档

按交接文件中"下次会话所需加载文档列表"逐一加载：

1. 优先从 `outputs/` 加载（正式版本）
2. 如不存在，从 `drafts/` 加载最新版本
3. 每加载一个文件输出：`[LOADED {文件路径}] ~{N} tokens`

### 第三步：输出恢复摘要

```
会话已恢复
─────────────────────────────────────────────
项目          {项目名称}
任务          {任务类型}（{编写/修订}）
中断原因      {容量不足/用户主动中断}
─────────────────────────────────────────────
已完成        {已完成内容简述}
断点位置      {具体断点}
待处理        {开放问题数量} 个开放问题
─────────────────────────────────────────────
```

### 第四步：从断点继续

- 按交接文件中"进行中内容"的断点位置继续执行
- 优先处理标记为最紧迫的开放问题
- 沿用交接文件中记录的生效假设，除非用户明确推翻

## 注意事项

- 本命令为豁免操作，自身不触发容量预检（只加载交接文件，开销极小）
- 加载关联文档后，正常触发容量计算（[LOADED] 标记累积）
- 如交接文件中列出的关联文档在 outputs/ 和 drafts/ 中均不存在，报告缺失，询问用户是否继续
