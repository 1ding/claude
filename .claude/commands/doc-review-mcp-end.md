# 单模型交互评审 — 结束

结束评审讨论，在评审报告中生成总结章节。

## 输入

$ARGUMENTS

格式示例：
```
/doc-review-mcp-end a1b2c3d4
```

## 参数解析

1.  提取会话 ID（第一个参数，8位字符串）

若参数不足，输出提示并中止：

> 用法：`/doc-review-mcp-end <session_id>`

## 执行步骤

### 1. 查找评审报告文件

在对话历史中查找该 session_id 对应的评审报告文件路径。
若找不到，用 Grep 在项目的 `review/` 目录中搜索包含该 session_id 的 `_review@*.md` 文件。

### 2. 追加总结章节

在评审报告文件末尾追加：

```
# {N} 评审总结

+ 评审状态：已完成
+ 讨论轮次：{总轮次}
+ 最终评审意见以最后一轮模型修订为准
```

章节编号 N 接续文件中已有的顶级章节号。
总轮次从文件中的讨论章节数统计。

### 3. 更新评审状态

将文件头部的 `+ 评审状态：进行中` 改为 `+ 评审状态：已完成`。

### 4. 输出结果

```
评审已完成，最终报告：{报告文件路径}

后续操作建议：
- /doc-revise <文件路径> ：整合评审意见执行修订
- /doc-review <文件路径> ：使用 Claude 执行深度内部质量检查
```
