# 加载约束规范

读取约束规范文件，适合文件类型不明确、或介于多种规范之间的情况。

## 用法

```
/load-spec /path/to/constraint-file.md         # 单文件（支持 .md 和 .yaml）
/load-spec /path/to/constraint-file.md 3       # 只加载第3章（仅 .md）
/load-spec /path/to/constraint-file.md 1-2     # 只加载第1、2章（仅 .md）
/load-spec /path/a.md /path/b.yaml             # 多文件
/load-spec /path/to/specs-dir/                 # 目录（加载所有支持的文件）
```

## 执行步骤

### 单文件模式（参数为单个文件路径，支持 .md 和 .yaml）

1.   读取指定文件
     - **章节过滤**（有章节参数时，仅 .md 文件支持）：按 `# ` 一级标题切分，序号从1开始，只保留指定章节；若无一级标题或序号越界，加载全文并告警。token 估算仅针对保留内容
2.   输出加载确认：
   ```
   [LOADED spec] {文件路径} | ~{字节数÷3.5取整} tokens
   ```

### 多文件模式（`路径1 路径2 ...`）

1.   依次识别参数中的多个路径（不支持章节参数）
2.   对每个文件逐一执行单文件模式步骤

### 目录模式（参数为目录路径）

1.   列出该目录下所有 `.md` 和 `.yaml` 文件（按文件名排序，同名前缀取最新版本）
2.   对每个文件逐一执行单文件模式步骤

### 加载后

扫描本次会话全部 `[LOADED *]` 记录，列出已加载文件清单及当前已用量汇总。
