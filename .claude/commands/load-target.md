# 加载目标文档

将指定文件读取到当前会话上下文，标记为目标文档。

## 用法

```
/load-target /path/to/file.md          # .md 文件
/load-target /path/to/file.yaml        # .yaml 文件
/load-target /path/to/file.md 4        # 只加载第4章（仅 .md）
/load-target /path/to/file.md 1-2      # 只加载第1、2章（仅 .md）
```

参数为具体文件路径（必填，不支持目录，支持 .md 和 .yaml）。章节参数可选，置于路径之后（仅 .md 文件支持）。

## 执行步骤

1.   **确定目标文件和章节范围**：
     - 用户必须在 `/load-target` 命令后提供文件路径
     - 若路径后附有章节参数（纯数字如 `4`，或范围如 `1-2`），记录章节范围
     - 如果用户未提供路径参数，提示："请提供文件路径，用法：/load-target /path/to/file.md"
2.   **读取目标文件**：使用 Read 工具读取步骤1中确定的文件路径的完整内容
     - **章节过滤**（有章节参数时）：按 `# ` 一级标题切分，序号从1开始，只保留指定章节（含标题行至下一个 `# ` 标题前的全部内容）；若文件无一级标题或序号越界，加载全文并告警。token 估算仅针对保留内容
3.   **输出加载确认**：
   ```
   [LOADED target] {文件路径} | ~{tokens数量} tokens
   [LOADED target] {文件路径} [章节 N] | ~{tokens数量} tokens        ← 有章节参数时
   [LOADED target] {文件路径} [章节 N-M] | ~{tokens数量} tokens      ← 有章节范围时
   ```
   - tokens 估算：文件字节数（或提取内容字节数）÷ 3.5，向下取整
4.   **汇总已加载文件**：扫描本次会话中所有 `[LOADED *]` 记录，列出文件清单及当前已用量汇总。

## 重要说明

- **必须提供路径**：命令必须带文件路径参数，格式为 `/load-target /path/to/file.md`
- **标记作用**：加载的文件被标记为"目标文档"，用于后续编写/修订操作的上下文
