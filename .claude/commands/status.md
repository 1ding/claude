# 会话状态总览

一键查看当前模型、所在项目、容量使用情况。

## 用法

```
/status
```

无参数。

## 执行步骤

### 1. 识别当前模型

从系统环境信息中提取当前使用的模型名称和 ID。

### 2. 识别当前项目

扫描会话历史，查找最近的 `[LOADED project]` 记录，提取项目名称。

若无 `[LOADED project]` 记录，则检查用户最近操作涉及的文件路径，尝试从 `projects/{项目}/` 模式中提取项目名。

若仍无法确定，显示"未切换项目"。

### 3. 估算容量

按容量管理规范计算：

-   **输入侧**：所有 `[LOADED *]` 记录中的 tokens 值之和
-   **输出侧**：所有 `[CAP DELTA]` 记录中的 tokens 值之和（无则为 0）
-   **固定储备**：50K tokens
-   **已用** = 输入侧 + 输出侧 + 50K
-   **剩余** = 1,000K − 已用

### 4. 输出状态报告

```
会话状态
═══════════════════════════════════════════════
模型          {模型名称}（{模型ID}）
项目          {项目名称 或 "未切换项目"}
═══════════════════════════════════════════════
容量使用
  输入侧      ~{A} tokens
  输出侧      ~{B} tokens
  固定储备     ~50,000 tokens
  ─────────────────────────────────────────
  已用合计     ~{Total} tokens（{P}%）
  剩余估算     ~{R} tokens（{Q}%）
═══════════════════════════════════════════════
容量状态：{状态}
```

容量状态判断：

-   剩余 > 250K（> 25%）→ 充裕
-   剩余 100K–250K（10%–25%）→ ⚠️ 偏紧
-   剩余 < 100K（< 10%）→ 🔴 不足
