# 查看当前会话容量状态

估算当前会话的上下文使用情况。

## 用法

```
/cap-status
```

无参数。

## 执行步骤

1. 扫描会话历史，汇总各项已用量：
   - **输入侧**：所有 `[LOADED *]` 记录中的 tokens 值之和
   - **输出侧**：所有 `[CAP DELTA]` 记录中的 tokens 值之和（无则为 0）
   - **固定储备**：50K tokens（系统 prompt + 版本管理规范 + 容量规范 + 对话文本积累）

2. 计算：
   - 已用 = 输入侧 + 输出侧 + 50K
   - 剩余 = 1,000K − 已用

3. 输出容量报告：

```
会话容量状态
─────────────────────────────────────────────
项目                           估算 tokens
输入侧（[LOADED *] 合计）      ~{A}
输出侧（[CAP DELTA] 合计）     ~{B}
固定储备                       ~50,000
─────────────────────────────────────────────
总计使用估算                   ~{A+B+50000}
剩余估算                       ~{R}
─────────────────────────────────────────────
基准容量：1,000K tokens（已用 {P}%，剩余 {Q}%）

状态：{见下}
```

容量状态判断：

- 剩余 > 250K（> 25%）→ ✅ 容量充裕
- 剩余 100K–250K（10%–25%）→ ⚠️ 容量偏紧，注意后续任务规模
- 剩余 < 100K（< 10%）→ 🔴 容量不足，参见容量管理规范决策树

> 注：实际 token 数以 Anthropic 计量为准，此处为估算值（误差约 ±20%）。
