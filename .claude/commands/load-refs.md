# 加载参考文档

将参考材料读取到当前会话上下文，供编写/修订时借鉴内容结构或素材。

## 用法

```
/load-refs /path/to/ref-file.md                            # 单文件
/load-refs /path/to/ref-file.md 4                          # 只加载第4章
/load-refs /path/to/ref-file.md 1-2                        # 只加载第1、2章
/load-refs /path/to/ref-file.md 用途：提供接口定义          # 注明用途（可选）
/load-refs /path/to/ref-file.md 1-2 用途：提供接口定义      # 章节 + 用途
/load-refs /path/a.md /path/b.md /path/c.md                # 多文件
/load-refs /path/to/refs/                                  # 目录（加载所有 .md）
```

## 执行步骤

### 单文件模式

1.   读取指定文件
     - **章节过滤**（有章节参数时）：按 `# ` 一级标题切分，序号从1开始，只保留指定章节；若无一级标题或序号越界，加载全文并告警。token 估算仅针对保留内容
2.   提取章节参数和用途说明（章节参数为路径后的纯数字或 `N-M`；用途说明以 `用途：` 开头；均为可选）
3.   输出加载确认：
   ```
   [LOADED refs] {文件路径} | ~{字节数÷3.5取整} tokens
   [LOADED refs] {文件路径} [章节 N] | ~{tokens数量} tokens
   ```

### 多文件模式（`路径1 路径2 ...`）

1.   依次识别参数中的多个路径（以空格分隔，路径以 `/` 开头或 `.` 开头）
2.   对每个文件逐一执行单文件模式步骤（不支持章节参数和用途说明）

### 目录模式（参数为目录路径）

1.   列出该目录下所有 `.md` 文件（按文件名排序，同前缀取最新版本）
2.   对每个文件逐一执行单文件模式步骤

### 加载后

扫描本次会话全部 `[LOADED *]` 记录，列出已加载文件清单及当前已用量汇总。
