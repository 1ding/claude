# 1 总则

+ **文档编号**：C11
+ **文档名称**：文档通用结构规范
+ **文档密级**：【内部资料】 -- 不主动对外公开。
+ **适用对象**：所有类型文档的结构设计与编写
+ **管理要点**：本规范是文档结构的权威约束，附录编号格式和标题格式以第 6.1 节为权威来源
+ **关联规范**：C01 内容表达规范、C02 排版格式规范、C99 天帷通用术语规范

+ 本规范定义文档的结构骨架，包括文档分类、分区要求、附录规范及修订记录格式，适用于所有类型文档的结构设计。

# 2 文档分类

+ 所有文档按内容性质分为三类，各类对应不同的结构要求。

| 分类   | 结构要求           | 适用类型                               |
| ------ | ------------------ | -------------------------------------- |
| 规范类 | 完整结构（五分区） | 编写规范、通用规范、过程规范、术语规范 |
| 交付类 | 完整结构（五分区） | 需求文档、设计文档、战略规划、测试报告 |
| 辅助类 | 简化结构           | 清单、记录、索引、模板                 |

# 3 完整结构规范

+ 规范类和交付类文档采用五分区结构，各分区按固定顺序排列。

## 3.1 分区顺序

- 总则（必选，首位）
- 正文（必选）
- 规范性附录（可选，排在资料性附录之前）
- 资料性附录（可选）
- 修订记录（必选，末位）

## 3.2 总则分区

+ **位置**：文档首位。
+ **标题格式**：`# 1 {标题}`，标题不强制使用"总则"，可根据内容命名（如"目的和范围""规范定位"）。
+ **必选要素**：文档编号、文档名称、文档密级。
+ **各类别补充要素**：
    - 规范类：补充适用对象、管理要点。
    - 交付类：补充编写目的、背景等。

## 3.3 正文分区

+ **起始标题**：`# 2`，之后各章连续编号。
+ **篇幅限制**：单一级标题下内容不超过 1 万汉字（用户可覆盖此限制）。

## 3.4 规范性附录分区

+ **性质**：执行配套，提供模板、文档骨架等可直接使用的内容。
+ **位置**：排在资料性附录之前。

## 3.5 资料性附录分区

+ **性质**：理解辅助，提供术语、方法论、教学说明、检查清单等参考内容。
+ **建议顺序**：术语表、文档说明。

## 3.6 修订记录分区

+ **位置**：文档末位，标题固定为 `# 修订记录`。
+ 详见第 7 章。

# 4 简化结构规范

+ 辅助类文档采用简化结构。

+ **必选部分**：标题、内容。
+ **可选部分**：修订记录。

+ 各类型的内容格式要求：

| 类型   | 内容格式                           |
| ------ | ---------------------------------- |
| 清单类 | 表格形式                           |
| 记录类 | 时间序列条目                       |
| 索引类 | 固定格式（如术语表的三层术语体系） |
| 模板类 | 可填充的结构                       |

# 5 密级规范

## 5.1 密级标签

+ 文档密级在总则分区中声明，采用以下标准标签：

| 密级     | 标签                                       |
| -------- | ------------------------------------------ |
| 商密一级 | 【商密一级】 -- 仅限指定人员，外发必追责。 |
| 商密二级 | 【商密二级】 -- 外发必追责。               |
| 内部资料 | 【内部资料】 -- 不主动对外公开。           |

+ **默认密级**：内部资料。

## 5.2 外发定义

+ "外发"指将文档传递给天帷体系外部的任何个人或组织。

# 6 附录规范

## 6.1 附录编号与标题格式

+ **编号规则**：附录按字母递增编号——附录A、附录B……
+ **排列顺序**：规范性附录排在资料性附录之前。
+ **标题格式**：
    - 规范性附录：`# 附录{字母}（规范性）{标题}`
    - 资料性附录：`# 附录{字母}（资料性）{标题}`

+ **一致性约束**：附录编号格式和标题格式以本节（6.1 节）为权威来源。

## 6.2 附录分类总表

| 类别   | 附录类型 | 性质   | 格式说明                                 | 详见    |
| ------ | -------- | ------ | ---------------------------------------- | ------- |
| 索引类 | 术语表   | 资料性 | 固定格式（三层术语体系）                 | 第6.3节 |
| 索引类 | 缩略语表 | 资料性 | 固定格式（表格）                         | 第6.4节 |
| 索引类 | 参考文献 | 资料性 | 固定格式（列表）                         | 第6.5节 |
| 配套类 | 裁剪规则 | 规范性 | 结构化（裁剪条件表 + 裁剪建议）          | 第6.6节 |
| 配套类 | 文档骨架 | 规范性 | 固定格式（代码块/模板）                  | 第6.7节 |
| 配套类 | 检查清单 | 资料性 | 固定格式（表格）                         | 第6.8节 |
| 配套类 | 模板集合 | 规范性 | 结构化（多个模板条目）                   | -       |
| 辅助类 | 文档说明 | 资料性 | 结构化（定位图 + 层级关系说明）或纯文字  | 第6.9节 |
| 辅助类 | 内容释义 | 资料性 | 自由组织                                 | -       |
| 辅助类 | 补充示例 | 资料性 | 自由组织                                 | -       |
| 辅助类 | 应用指南 | 资料性 | 自由组织                                 | -       |

+ 注：标注"-"的附录类型无固定格式要求，按内容需要自由组织。

## 6.3 术语表

+ **附录类别**：索引类 / 资料性。

+ 术语表采用三层结构，各层要求不同：

| 层级         | 内容要求          |
| ------------ | ----------------- |
| 业界通用术语 | 仅列名称          |
| 天帷通用术语 | 列名称 + 引用 C99 |
| 文档专有术语 | 完整定义          |

## 6.4 缩略语表

+ **附录类别**：索引类 / 资料性。
+ **格式**：表格，列出缩略语及其全称。

## 6.5 参考文献

+ **附录类别**：索引类 / 资料性。
+ **格式**：有序列表，列出引用文献的必要信息。

## 6.6 裁剪规则

+ **附录类别**：配套类 / 规范性。
+ **格式**：结构化，包含裁剪条件表和裁剪建议两部分。

## 6.7 文档骨架

+ **附录类别**：配套类 / 规范性。
+ **格式**：代码块或模板，呈现文档的可填充结构。

## 6.8 检查清单

+ **附录类别**：配套类 / 资料性。
+ **格式**：表格，列出可逐项核对的检查项。

## 6.9 文档说明

+ **附录类别**：辅助类 / 资料性。
+ **格式**：结构化（定位图 + 层级关系说明）或纯文字，说明文档在体系中的定位与关系。

# 7 修订记录规范

## 7.1 表格格式

+ 修订记录采用表格形式，列顺序固定：

```text
| 版本号 | 日期 | 修订内容 | 修订人 |
```

+ **版本号格式**：
    - 正式版本：主版本.次版本（如 0.10、1.00）。
    - AI 修订临时版本：R.{nn}（R.01、R.02……顺序递增），用户指示时才归并为正式版本号。

+ **行宽约束**：每行显示宽度不超过 180。中文字符及中文符号各占 2 个显示宽度；英文字符及英文符号各占 1 个显示宽度。

+ **排列顺序**：按时间正序排列（最早版本在上，最新版本在下）。

## 7.2 归并规则

+ R 转正式版本号时，只描述最终结果与该版本原始状态的差异，不体现中间演变过程。
