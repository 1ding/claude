# 1 总则

+ 文档编号：C02
+ 文档名称：排版格式规范
+ 文档密级：【内部资料】 -- 不主动对外公开。
+ 适用对象：所有项目文档编写人员（含 AI）。
+ 管理要点：本规范是项目文档 Markdown 排版格式的权威来源，规定符号使用、禁用语法、标题层级、缩进、表格、图、代码块、公式及 HTML 标签等要求，所有文档应严格遵守。

# 2 Markdown 符号

## 2.1 符号定义

+ 本规范使用的 Markdown 符号及其用途如下：

| 符号    | 用途                                               |
| ------- | -------------------------------------------------- |
| `+`     | 通用内容行标记（段落、说明、描述等所有非列表内容） |
| `-`     | 列表项标记（仅用于真正的枚举/并列项）              |
| `#`     | 标题标记                                           |
| ` ``` ` | 代码块/图块起止标记                                |

## 2.2 缩进单位

+ 缩进单位为 **4 空格/层**，所有层级缩进均以此为基数。

## 2.3 核心规则

+ 除标题（`#`）、列表项（`-`）、代码块（` ``` `）三类行外，所有内容行应以 `+` 开头。
+ 普通段落、说明文字、描述、注意事项等，均使用 `+` 标记，不应使用空段落或其他符号。

# 3 禁用语法

+ 以下 Markdown 语法不应在本规范约束的文档中使用：

- `>` 引用块
- `[^]` 脚注
- `- [ ]` 任务列表
- `---` 或 `***` 分隔线（表格内部的表头分隔行除外）
- `*` 作为列表符号

# 4 标题层级

## 4.1 层级格式

+ 标题最多使用 6 级，各级格式如下所示。

    ```text
    # 1 一级标题
    ## 1.1 二级标题
    ### 1.1.1 三级标题
    #### 四级标题
    ##### 五级标题
    ###### 六级标题
    ```

## 4.2 注意事项

+ 正文从 `#`（一级标题）开始；不应在一级标题上方设置文档名称标题。
+ 标题层级应按顺序递进，不应跳级（如从一级直接跳到三级）。

# 5 缩进规则

+ 各场景的缩进规则分别如下。

- **标题下直接跟随的 `+`**：不缩进，紧贴左边界。
- **嵌套内容**：每深一层缩进 4 空格。
- **列表项 `-`**：与同级 `+` 保持相同缩进深度。
- **`-` 下的子级**：子 `-` 或子 `+` 在父 `-` 基础上再缩进 4 空格。
- **嵌套自由度**：`+` 下可嵌套 `-`，`-` 下可嵌套 `+`，自由组合。

+ 以下示例展示了各层级缩进的典型用法。

    ```text
    + 段落内容（不缩进）
        + 嵌套内容（缩进 4 空格）
    - 列表项
        - 子列表项（缩进 4 空格）
        + 列表项下的说明（缩进 4 空格）
    ```

# 6 表格

## 6.1 语法

+ 使用标准 Markdown 表格语法：`|` 分隔列，`---` 定义表头分隔行。

## 6.2 格式规则

- **表头**：应填写，不得留空。
- **行宽限制**：每行显示宽度不得超过 **360**（中文字符及中文符号各计 2，英文字符、数字及英文符号各计 1）。
- **换行**：不应使用 `<br>` 换行；内容需换行时，拆分为多行（每行对应独立内容）。
- **对齐**：填充空格以确保等宽字体下各列视觉对齐。

+ 以下示例展示了标准表格的格式。

    ```text
    | 列A    | 列B      |
    | ------ | -------- |
    | 内容 1 | 内容说明 |
    | 内容 2 | 内容说明 |
    ```

# 7 图

## 7.1 图形类型

+ 仅允许使用 **ASCII 文本图**；不应嵌入图片文件或使用非文本图形。

## 7.2 代码围栏

+ 图块的代码围栏语言标识为 ` ```graph `（`graph` 为本规范定义的自定义标识符）。
+ 以下代码块展示了图块的典型格式。

    ```graph
    ┌─────────────┐
    │  示例图块   │
    └─────────────┘
    ```

## 7.3 格式规则

- **行宽限制**：每行显示宽度不得超过 **360**（计算规则同第 6.2 节）。
- **推荐字符**：`─ │ ┌ ┐ └ ┘ ├ ┤ ┬ ┴ ┼ ▶ ▼ ◆ ●`
- **禁用字符**：不应将 `+`、`-`、`|`、`*` 作为图形绘制元素使用。
- **对齐**：同级元素须水平或垂直对齐；同类元素须保持相同大小。

# 8 图表标题与说明

## 8.1 说明文字

+ 说明文字置于图/表**上方**，使用完整陈述句，**不以冒号结尾**。
+ 说明文字使用 `+` 行标记，不缩进。

## 8.2 标题

+ 标题置于图/表**下方**，使用简洁的名词短语。

## 8.3 缩进关系

+ 图、表、代码块相对其上方的说明文字**缩进 4 空格**，以体现从属关系。

## 8.4 编号与引用

- **编号**：图/表**不编号**。
- **引用**：使用位置性语言（"上图"/"下表"/"以下代码"）或直接引用标题文字；不应使用"图1"/"表2"等编号引用。

# 9 代码块

## 9.1 语言标签

+ 代码块应注明语言标签，不应省略。常用标签如下：

- `json`、`yaml`、`toml`：配置/数据格式
- `python`、`java`、`typescript`、`go`：编程语言
- `sql`：数据库查询
- `bash`：Shell 命令
- `text`：纯文本/无特定语言

## 9.2 嵌套场景

+ 代码块嵌套时，外层使用 4 空格缩进处理，不应使用反引号嵌套。

# 10 公式

+ 公式使用 LaTeX 语法，分行内与块级两种形式：

| 类型     | 格式      | 示例                      |
| -------- | --------- | ------------------------- |
| 行内公式 | `$...$`   | `$E = mc^2$`              |
| 块级公式 | `$$...$$` | `$$\sum_{i=1}^{n} x_i$$` |

# 11 允许的 HTML 标签

+ 正文中仅允许使用以下 4 种 HTML 标签，不应使用其他 HTML 标签：

| 标签     | 用途   | 示例                    |
| -------- | ------ | ----------------------- |
| `<sup>`  | 上标   | `文字<sup>注</sup>`     |
| `<sub>`  | 下标   | `H<sub>2</sub>O`        |
| `<mark>` | 高亮   | `<mark>重点内容</mark>` |
| `<u>`    | 下划线 | `<u>下划线文字</u>`     |
