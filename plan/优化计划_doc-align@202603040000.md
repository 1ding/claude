# 优化计划：/doc-align 命令

**创建时间**：2026-03-04 00:00
**目标文件**：`.claude/commands/doc-align.md`
**附带修改**：`.claude/commands/doc-resume.md`

## 优化目标

当前 `/doc-align` 的不足：
1. 差异报告仅存在于会话对话中，会话结束即丢失
2. 无容量感知：不检查已加载文档是否接近 200K 限制
3. 修正阶段无分批策略：文档量大时可能超出上下文
4. 无法跨会话恢复：发现差异后如需新会话修正，无机制支持

优化后：
- 差异报告 + 修正方案自动保存为**对齐计划文件**（`对齐计划_*.md`），可跨会话使用
- 新增容量预估步骤，按负载自动选择修正策略（本会话 / 分批 / 移交新会话）
- `/doc-resume` 支持识别 `对齐计划_` 前缀文件，实现统一恢复入口
